## Sobre o projeto
Aplicação web para a gestão de condomínios.
O *RD Condomínios* é um sistema que permite centralizar a informação de gestão de condomínios num único local, de forma organizada e fácil de consultar. Através de uma interface web simples, o responsável pela gestão pode registar e acompanhar as moradias, os moradores, as quotas mensais, as despesas comunus e as obras.

## Principais funcionalidades
- Registo e consulta das moradias do condomínio;
- Gestão dos moradores associados a cada moradia (proprietários e inquilinos)
- Controlo das quotas mensais e identificação de pagamentos em atraso
- Registo das despesas comuns;
- Acompanhamento de obras (desde o pedido à conclusão)

## Tecnologias
- **Python** - Linguagem de programação
- **Flask** - framework web
- **SQLite** - base de dados
- **HTML, CSS e Jinja2** - interface
